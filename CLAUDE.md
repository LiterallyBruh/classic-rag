# CLAUDE.md — контекст проекта ClassicRAG

## Что это и зачем

RAG-ассистент по классической литературе: отвечает на вопросы по текстам
произведений **только с опорой на первоисточник**, с цитатами и ссылкой на
часть/главу. Проект готовится для **Junior ML Contest (AI Talent Hub, ИТМО)**,
победа даёт БВИ при поступлении в магистратуру.

## Жёсткие дедлайны

- **20 июля 2026** — подача заявки (репозиторий, описание до 3 стр., презентация, CV, мотивационное письмо)
- **21–22 июля** — запись на защиту
- **27–29 июля** — питчинг: 5 мин презентация + 7 мин вопросы жюри

## Критерии оценки жюри (оптимизируем под них)

1. **Инженерия:** git-гигиена, Docker, CI, тесты, качество кода, воспроизводимый пайплайн
2. **Data Science:** EDA, предобработка, обоснованный выбор моделей, метрики, валидация
3. **Применение AI-инструментов:** фиксировать КАЖДОЕ использование LLM в разработке в `docs/ai_usage_log.md`
4. **Продукт:** проблема (LLM галлюцинируют про классику), ЦА (школьники/ЕГЭ, студенты, преподаватели), MVP, реальный фидбек пользователей
5. **Мотивация** — вне кода

## Корпус (всё в общественном достоянии — не менять без проверки прав!)

«Преступление и наказание», «Идиот», «Бесы» (Достоевский),
«Фауст» строго в переводе **Н. Холодковского** (переводы Пастернака и др.
современные — под охраной, использовать нельзя).

## Архитектура

тексты → очистка → структурная разметка (часть/глава/сцена) → чанкинг
→ BM25 + dense (multilingual-e5-base, префиксы query:/passage:) → RRF
→ reranker (bge-reranker-v2-m3) → нормализация имён персонажей
(configs/characters.yaml) → генерация с обязательным цитированием
→ отказ отвечать, если ответа нет во фрагментах

## Правила работы

- **Каждое дизайн-решение** (выбор модели, стратегия чанкинга, параметры)
  документировать с аргументацией — комментарием в коде или в `docs/decisions.md`.
  Это заготовки ответов жюри.
- Любой эксперимент → метрики в `eval/report.md` (таблицы «до/после»)
- Не коммитить тексты книг (`data/` в .gitignore) и секреты (`.env`)
- Коммиты — осмысленные, по-английски, атомарные; CI должен оставаться зелёным
- Перед коммитом: `ruff check .` и `pytest -q`
- Python 3.11, зависимости — только через pyproject.toml
- Секреты LLM: переменные `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` из `.env`
