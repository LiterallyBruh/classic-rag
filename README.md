# 📚 ClassicRAG — вопросно-ответная система по русской и мировой классике

RAG-ассистент, который отвечает на вопросы по текстам классических произведений
**только с опорой на первоисточник** — с точными цитатами и указанием части/главы.

**Проблема:** универсальные LLM галлюцинируют цитатами и фактами из классики.
Для школьников (ЕГЭ), студентов и преподавателей это делает их непригодными.

**Решение:** гибридный retrieval (BM25 + dense) по структурно размеченному
корпусу + генерация строго по найденным фрагментам. Если ответа в тексте нет —
система честно сообщает об этом.

## Корпус (общественное достояние)

| Произведение | Автор | Особенности для retrieval |
|---|---|---|
| Преступление и наказание | Ф. М. Достоевский | длинные внутренние монологи |
| Идиот | Ф. М. Достоевский | плотные диалоговые сцены |
| Бесы | Ф. М. Достоевский | большое число персонажей и алиасов |
| Фауст (пер. Н. Холодковского) | И. В. Гёте | драма в стихах, чанкинг по репликам |

## Архитектура

```
тексты → очистка → структурная разметка (часть/глава/сцена)
      → чанкинг (3 стратегии, сравнение по метрикам)
      → индексация: BM25 + dense (multilingual-e5-base), файловый индекс
запрос → нормализация имён персонажей (словарь алиасов)
      → гибридный поиск (RRF) → reranker (bge-reranker-v2-m3)
      → генерация с обязательным цитированием → ответ + ссылки на главы
```

Каждое дизайн-решение с аргументацией — в `docs/decisions.md`.

## Ключевые результаты (120 верифицированных вопросов, eval/report.md)

- Рабочая конфигурация **window + reranker**: span recall@1 **0.39**,
  recall@5 **0.57**, MRR **0.47** — против 0.23/0.42/0.32 без реранкера.
- Сравнение трёх стратегий чанкинга: высокий recall чанков-глав — артефакт
  их размера, для продукта выбраны окна ~180 слов с перекрытием.
- Каждый eval-вопрос программно верифицирован против корпуса
  (`scripts/verify_eval.py`, 120/120).

## Быстрый старт

```bash
# Docker (рекомендуется):
docker compose up --build   # bootstrap сам скачает корпус и построит индекс

# или локально:
pip install -e ".[dev]"
python scripts/bootstrap.py
streamlit run app/main.py
```

LLM-ключ (`.env`, см. `.env.example`) необязателен: без него демо показывает
найденные фрагменты без генерации ответа. Деплой на HF Spaces — `docs/deploy.md`.

## Структура

- `scripts/` — загрузка, очистка, разметка, индексация, бутстрап
- `src/classic_rag/` — чанкинг, retrieval, reranker, нормализация, генерация, пайплайн
- `eval/` — вопросный набор, метрики, отчёт
- `notebooks/` — EDA корпуса
- `app/` — Streamlit-демо
- `tests/` — pytest, запускаются в CI
