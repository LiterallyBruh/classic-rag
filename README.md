# 📚 ClassicRAG — вопросно-ответная система по русской и мировой классике

RAG-ассистент, который отвечает на вопросы по текстам классических произведений
**только с опорой на первоисточник** — с точными цитатами и указанием части/главы.

**Проблема:** универсальные LLM галлюцинируют цитатами и фактами из классики
(проверено: см. `eval/hallucination_examples.md`). Для школьников (ЕГЭ),
студентов и преподавателей это делает их непригодными.

**Решение:** гибридный retrieval (BM25 + dense) по структурно размеченному
корпусу + генерация строго по найденным фрагментам. Если ответа в тексте нет —
система честно сообщает об этом.

## Корпус (общественное достояние)

| Произведение | Автор | Особенности для retrieval |
|---|---|---|
| Преступление и наказание | Ф. М. Достоевский | длинные внутренние монологи |
| Идиот | Ф. М. Достоевский | плотные диалоговые сцены |
| Бесы | Ф. М. Достоевский | большое число персонажей и алиасов |
| Фауст (пер. Н. Холодковского) | И. В. Гёте | драма в стихах, чанкинг по репликам |

## Архитектура

```
тексты → очистка → структурная разметка (часть/глава/сцена)
      → чанкинг (3 стратегии, сравнение по метрикам)
      → индексация: BM25 + dense (multilingual-e5) в Qdrant
запрос → нормализация имён персонажей (словарь алиасов)
      → гибридный поиск → reranker (bge-reranker-v2-m3)
      → генерация с обязательным цитированием → ответ + ссылки на главы
```

## Быстрый старт

```bash
docker compose up --build        # поднимает Qdrant + приложение
# или локально:
pip install -e ".[dev]"
python scripts/download_texts.py
python scripts/build_index.py
streamlit run app/main.py
```

## Структура

- `scripts/` — загрузка, очистка, разметка, индексация
- `src/classic_rag/` — retrieval, нормализация, генерация
- `eval/` — вопросный набор, метрики, отчёт
- `app/` — Streamlit-демо
- `tests/` — pytest, запускаются в CI
